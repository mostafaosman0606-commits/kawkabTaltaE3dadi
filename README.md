# 🪐 منصة «كوكب تالتة إعدادي» — Kawkab Talta E3dadi
> **المنصة التعليمية المتكاملة لطلاب الشهادة الإعدادية في جمهورية مصر العربية**

منصة تعليمية متكاملة (Full-Stack Educational Platform) مخصصة لطلاب الصف الثالث الإعدادي في مصر، مبنية بأحدث معايير الويب والتصميم التفاعلي (Space Atmosphere Design)، وتتضمن دعماً كاملاً للمواد الدراسية الثمانية، بنك امتحانات مقالية وموضوعية مع نظام مراقبة ومكافحة غش، تصحيح ذكي يدوي ومعان بالذكاء الاصطناعي، إصدار شهادات تفوق رسمية موثقة بـ QR Code، تحديات طلابية مباشرة، ومساعد ذكي «روبو».

---

## 🌟 الميزات الرئيسية للمنصة

### 1. الهوية البصرية الفضائية (Space Atmosphere UI/UX)
- تصميم كحلي وداكن أنيق مستوحى من الفضاء والكواكب (`#070b14` / `#0f172a`).
- خلفية فضائية تفاعلية تحوي نجوماً لامعة وشهباً وسدماً متحركة عبر Canvas عالي الأداء.
- خطوط عربية مصرية راقية ومقروءة (`Cairo` & `Alexandria`) مع محاذاة RTL كاملة لكافة الشاشات.

### 2. المواد الدراسية الثمانية للشهادة الإعدادية
1. **اللغة العربية:** النحو (المنادى، البدل، أسلوب المدح والذم، الممنوع من الصرف)، القراءة، النصوص الأدبية، وقصة طموح جارية.
2. **الرياضيات:** الجبر، حاصل الضرب الديكارتي، العلاقات والدوال، حساب المثلثات، والهندسة التحليلية.
3. **اللغة الإنجليزية:** منهج New Hello! Prep 3 والقواعد والكلمات والمحادثات.
4. **العلوم:** القوى والحركة، السرعة والعجلة، الطاقة الضوئية، الكون والنظام الشمسي.
5. **الدراسات الاجتماعية:** جغرافيا قارات العالم وتاريخ مصر الحديث والمعاصر.
6. **التربية الدينية الإسلامية:** سورة لقمان، أحكام التجويد، والعقيدة والعبادات.
7. **الحاسب وتكنولوجيا المعلومات:** حل المشكلات وخرائط التدفق وأساسيات Visual Basic.Net.
8. **التربية الفنية:** التراث والفن الشعبي والقبطي والتصميم الابتكاري.

### 3. نظام الدروس والملاحظات التفاعلية
- شرح تفصيلي مكتوب مدعم بالمعادلات والخرائط الذهنية.
- مشغل فيديو تفاعلي (فيديوهات يوتيوب وروابط مباشرة).
- ملخصات الدروس ومذكرات PDF قابلة للتحميل والطباعة.
- **دفتر ملاحظات خاص ومستقل لكل طالب:** يتم حفظه تلقائياً في قاعدة البيانات ولا يطلع عليه طالب آخر.
- زر «تأكيد إنهاء الدرس» مع علامة إنجاز رسمية: **«تم الانتهاء بالفعل»**.

### 4. محرك الامتحانات ومكافحة الغش (Exam Engine & Anti-Cheat)
- أسئلة اختيار من متعدد (MCQ)، صواب أو خطأ، وأسئلة مقالية تفصيلية.
- مؤقت تنازلي ذكي مع التسليم التلقائي عند انتهاء الوقت.
- **نظام كشف تبديل النوافذ ومغادرة الصفحة (Anti-Cheating Safeguards):** يكتشف تصغير النافذة أو فتح تبويب جديد، وينبه الطالب بنافذة تحذيرية، ويسجل المخالفة مع توقيتها في تقرير المراقب الأكاديمي.
- **تصحيح خادم رسمي (Server-side Grading):** لا يتم الوثوق بأي نتيجة من المتصفح، بل يقوم المحرك بمقارنة الإجابات وحساب الدرجات بدقة.
- التمييز الواضح بين النتائج المبدئية (بانتظار تصحيح المقالي) والنتائج النهائية المعتمدة.

### 5. تصحيح الأسئلة المقالية ودعم الذكاء الاصطناعي
- طابور مخصص للمعلمين لمراجعة الأسئلة المقالية وإعطاء التغذية الراجعة.
- نموذج إجابة وزاري ومعايير توزيع الدرجات (Rubric).
- تقييم استرشادي ذكي يقارن إجابة الطالب بنموذج الإجابة ويقترح درجة وملاحظة للمعلم.
- إمكانية قيام المعلم بتعديل الدرجة واعتمادها لتصل للطالب فوراً.

### 6. شهادات التفوق والتميز (Certificates)
- توليد فوري للشهادات عند اجتياز الامتحان بنجاح (>= 60%).
- تتضمن: اسم الطالب، اسم المادة، اسم الامتحان، النسبة المئوية، التاريخ، رقم تسلسلي فريد، ورمز QR للتحقق.
- إمكانية طباعة أو حفظ الشهادة بصيغة PDF بجودة عالية.

### 7. المعلم الذكي «روبو» 🤖
- مساعد تعليمي يتحدث بأسلوب مشجع ومناسب لطلاب تالتة إعدادي.
- تقسيم المسائل والمفاهيم المعقدة إلى خطوات بسيطة وتفاعلية.
- إمكانية رفع صور المسائل والأسئلة من الكتب لمناقشتها.
- حصص استهلاك شهرية مقننة بناءً على باقة الاشتراك.

### 8. تحديات كوكب تالتة المباشرة (Live Challenges)
- توليد كود دعوة خاص لكل تحدٍ ومشاركته مع الأصدقاء.
- مبارزة سريعة من 5 أسئلة في 60 ثانية لحصد نقاط الترتيب.
- منصة تتويج فوري وإعلان الفائز.

### 9. لوحة الشرف وقائمة الأوائل (Leaderboard)
- ميداليات ذهبية 🥇 وفضية 🥈 وبرونزية 🥉 للأوائل.
- تصفية حسب المحافظة والتوقيت (تراكمي أو شهري).
- معادلة احتساب معتمدة تمنع التلاعب أو تكرار المحاولات.

### 10. الاشتراكات وإدارة المدفوعات (Subscriptions)
- ثلاث باقات: **مجانية (Free)**، **قياسية (Standard)**، و**مميزة (Premium)**.
- دعم طرق الدفع الشائعة في مصر (فودافون كاش، إنستاباي InstaPay، وفوري).
- رفع إيصال التحويل (Screenshot) لمراجعته من مسؤولي المنصة قبل تفعيل الباقة.

## 🛠️ البنية التقنية (Architecture)

- **Frontend:** React 19 + TypeScript + Vite.
- **Styling:** Tailwind CSS v4 + Tailwind Merge + Lucide Icons.
- **Backend / Storage (Dual-Engine Architecture):**
  1. **محرك التخزين المستمر المدمج (Local Persistence Engine):** يعمل افتراضياً دون إعدادات معقدة لحفظ بيانات الطلاب والامتحانات والشهادات.
  2. **سحابة Supabase Cloud (PostgreSQL + RLS):** مخطط SQL جاهز مع صلاحيات أمان على مستوى الصفوف (Row Level Security).
- **Security:** عزل كامل لصلاحيات الطلاب عن المشرفين والمديرين، وتشفير بيانات الاتصال، وتسجيل العمليات الإدارية الحساسة في سجل (Audit Logs).

## 🚀 التشغيل والتثبيت المحلي (Local Setup)

```bash
# 1. الدخول إلى مجلد المشروع
cd kawkab-talta-e3dadi

# 2. تثبيت الحزم والمكتبات
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:5173`.

## 🗄️ إعداد قاعدة بيانات Supabase (اختياري للإنتاج)

1. أنشئ مشروعاً جديداً على [Supabase](https://supabase.com).
2. افتح **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتويات الملف:
   `supabase/migrations/20261015000000_init_kawkab_schema.sql`
   وقم بتنفيذه في نافذة الـ SQL Editor لإنشاء جميع الجداول والأنواع وسياسات الأمان (RLS).
4. انسخ بيانات الاتصال إلى ملف `.env`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key-here
   ```
5. أعد تشغيل التطبيق وسيقوم بالاتصال السحابي تلقائياً!

## 🌐 النشر خارج Bolt (Deployment Outside Bolt)

### 1. النشر على Vercel
- قم برفع المشروع على حسابك في GitHub.
- استورد المشروع في Vercel، وستكتشف إعدادات Vite تلقائياً:
  - **Build Command:** `npm run build`
  - **Output Directory:** `dist`
- أضف متغيرات البيئة (`VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`) في صفحة Settings > Environment Variables.

### 2. النشر على Netlify
- اربط مستودع GitHub واختر:
  - **Build Command:** `npm run build`
  - **Publish directory:** `dist`

### 3. النشر على استضافة VPS أو خادم Nginx
قم ببناء المشروع:
```bash
npm run build
```
وانقل محتويات مجلد `dist/` إلى مسار الويب الخاص بـ Nginx (مثل `/var/www/html`).
